# Review guidance

## Triage presentation

Use one-at-a-time triage by default, following the steering presentation layout. No project-specific layout override is established.

Batch triage presents the consolidated findings with recommendations so the user can provide feedback or choose an action to carry out.

Automatic triage may apply findings without individual confirmation unless the finding requires a decision or presents an open question.

Severity definitions are in `.agents/steering/review.md`.
